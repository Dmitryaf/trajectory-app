# Развёртывание и ИИ-интеграция

## Текущий статус

Приложение уже является PWA:

- есть web app manifest;
- есть service worker через `vite-plugin-pwa`;
- production-сборка создаётся командой `npm run build`;
- данные хранятся локально в IndexedDB;
- есть экспорт/импорт JSON;
- есть пакет для ИИ-анализа недели и месяца.

## Как получить веб-приложение

Минимальный путь:

1. Залить проект в GitHub.
2. Подключить репозиторий к Vercel, Netlify или Cloudflare Pages.
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. Получить HTTPS-домен.

PWA-установка на телефон и компьютер нормально работает только с HTTPS-домена или с `localhost`.

## Как будет выглядеть ИИ

Правильная архитектура:

```text
Vue PWA -> backend/edge function -> OpenAI Responses API -> структурированный JSON -> UI приложения
```

Нельзя вызывать OpenAI API напрямую из браузера с постоянным API-ключом. Ключ должен жить на сервере или в edge function.

## Что отправлять в ИИ

Не сырой поток всех данных, а агрегированный пакет:

- период: неделя или месяц;
- summary: сон, энергия, карьера, движение, результаты;
- observations: локальные наблюдения приложения;
- factorSummaries: вечерние факторы;
- entries: дневные записи выбранного периода;
- weeklyReview: ручной недельный обзор, если есть.

Такой пакет уже можно получить в настройках: `Пакет для ИИ-анализа`.

## Что ИИ должен возвращать

Лучше возвращать строгий JSON:

```json
{
  "summary": "Короткая сводка фактов",
  "supportingFactors": ["..."],
  "blockingFactors": ["..."],
  "hypotheses": ["..."],
  "nextLever": "...",
  "caveats": ["..."]
}
```

В интерфейсе это можно показать как отдельный блок в неделе и месяце.
