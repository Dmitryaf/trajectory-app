# Проверка первого использования

Дата: 8 августа 2026 года.

## Результат

Локальная граница первого использования готова к поставке на staging. Основной путь, прерывание, старые данные, ошибки сохранения, резервная копия, облачная очередь и адаптивность проверяются автоматически. Содержимое пользовательских ответов не попадает в локальную воронку.

Эта проверка не заменяет smoke-тест уже развёрнутой ветки. Регистрация с подтверждением email, реальный staging Supabase и обновление PWA проверяются после публикации и относятся к следующему этапу поставки.

## Команды

```text
npm.cmd run check
npm.cmd run test:e2e
git diff --check
```

Перед поставкой на staging эти команды выполняются ещё раз после последнего изменения.
