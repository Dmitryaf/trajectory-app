# Инструкции для агента

Маршрутизация:

1. [WORKFLOW.md](./WORKFLOW.md) — в начале новой задачи;
2. [QUALITY.md](./QUALITY.md) — перед выбором и запуском проверок;
3. [PRODUCT.md](./PRODUCT.md) — только для продуктовых, текстовых и интерфейсных изменений.

Для изменений данных и аналитики также обязателен [PRODUCT_RULES.md](../product/PRODUCT_RULES.md).
В пределах одного непрерывного блока не перечитывать неизменившиеся инструкции повторно.
