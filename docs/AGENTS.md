# Правила работы агента

Инструкции находятся в `docs/agent/`:

- `docs/agent/WORKFLOW.md` — разбиение и выполнение задач;
- `docs/agent/QUALITY.md` — самопроверка и критерии готовности;
- `docs/agent/PRODUCT.md` — продуктовые и интерфейсные ограничения.

Перед новой задачей прочитай `WORKFLOW.md`, затем открывай только относящиеся к задаче разделы. В `QUALITY.md` канонические решения для затронутого класса повторяющихся регрессий читаются до реализации, остальные критерии — перед проверкой. `PRODUCT.md` и `docs/product/PRODUCT_RULES.md` читай при продуктовых, текстовых или аналитических решениях. Не перечитывай неизменившиеся документы внутри одного непрерывного блока работы. Навигация по остальной документации находится в `docs/README.md`.
