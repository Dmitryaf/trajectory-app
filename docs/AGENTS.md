# Правила работы агента

Полные инструкции находятся в `docs/agent/`:

- `docs/agent/WORKFLOW.md` — разбиение и выполнение задач;
- `docs/agent/QUALITY.md` — самопроверка и критерии готовности;
- `docs/agent/PRODUCT.md` — продуктовые и интерфейсные ограничения.

Перед изменениями прочитай все три файла и релевантные документы, на которые они ссылаются.
