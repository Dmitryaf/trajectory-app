# Правила работы агента

Инструкции находятся в `docs/agent/`:

- `docs/agent/WORKFLOW.md` — разбиение и выполнение задач;
- `docs/agent/QUALITY.md` — самопроверка и критерии готовности;
- `docs/agent/PRODUCT.md` — продуктовые и интерфейсные ограничения.

Перед новой задачей прочитай `WORKFLOW.md`, затем открывай только относящиеся к задаче разделы: `QUALITY.md` перед проверкой, `PRODUCT.md` и `PRODUCT_RULES.md` — при продуктовых, текстовых или аналитических решениях. Не перечитывай неизменившиеся документы внутри одного непрерывного блока работы.
