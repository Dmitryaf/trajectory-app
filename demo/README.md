# Данные тестового пользователя

`trajectory-test-user-2026-07-20.json` — актуальный снимок тестового аккаунта по состоянию на 20 июля 2026 года.

Он содержит данные с мая по июль и специально покрывает новые сценарии: несколько карьерных значений за день, пользовательские и архивные варианты, факторы перед сном, особые дни, эксперимент, длинные списки итогов и событий, недельные и месячные обзоры. Измерения веса заканчиваются текущей датой — будущих и прогнозных значений нет.

## Как обновить тестовый аккаунт

1. Войти именно в тестовый аккаунт.
2. Открыть «Ещё» → «Настройки и данные».
3. Сначала скачать текущую копию, если её нужно сохранить.
4. Нажать «Загрузить копию» и выбрать JSON-файл из этой папки.
5. Дождаться статуса успешной облачной синхронизации.

Импорт полностью заменяет данные открытого аккаунта. Публичная регистрация отключена, поэтому новый тестовый аккаунт при необходимости создаётся владельцем проекта через Supabase.

Чтобы пересобрать снимок после изменения генератора, выполните `npm run demo:generate`.
