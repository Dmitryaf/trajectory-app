# Данные для тестирования

Генератор создаёт полную резервную JSON-копию относительно выбранной опорной даты. Исходный сценарий не содержит реальных пользовательских данных и не требует ручного переноса дат.

## Локальная проверка

Создать набор относительно сегодняшнего дня:

```powershell
npm.cmd run demo:generate
```

Результат появится в `demo/generated/trajectory-full.json`. В локально запущенном приложении откройте «Настройки» → «Данные и синхронизация» → «Восстановить из копии» и выберите этот файл. Облако для импорта не требуется: без облачной сессии данные сохраняются только в IndexedDB текущего браузера.

Импорт полностью заменяет локальные записи, итоги, события, обзоры и настройки. Если текущие данные нужны, сначала скачайте резервную копию.

## Воспроизводимый набор

Для проверки на конкретной дате передайте её явно:

```powershell
npm.cmd run demo:generate -- --anchor=2026-08-11
```

Можно указать другой файл:

```powershell
npm.cmd run demo:generate -- --anchor=2026-08-11 --output=demo/generated/check-2026-08-11.json
```

Опорная дата задаётся в формате `YYYY-MM-DD`. Генератор создаёт записи примерно за четыре календарных месяца, завершённые недельные и месячные обзоры, длинные списки итогов и событий, особые дни, пользовательские настройки, активный и завершённый эксперименты с дневными заметками. Будущие дневные записи и измерения не создаются.

## Автоматические тесты

Модульные тесты строят снимок в памяти на фиксированной дате. Playwright перед запуском создаёт `trajectory-full.json` относительно текущего дня и загружает его через тот же интерфейс, что используется для обычной резервной копии.

JSON внутри `demo/generated/` является воспроизводимым артефактом и не хранится в Git. При изменении сценария нужно менять `scripts/generate-test-user-data.mjs`, а не готовый файл.
