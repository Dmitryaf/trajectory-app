# Demo data

Файл `trajectory-demo-week-2026-07-13-2026-07-19.json` можно импортировать в отдельный демо-аккаунт через настройки приложения.

Рекомендуемый порядок:

1. Создать отдельного пользователя в Supabase Auth или через экран регистрации приложения.
2. Войти в приложение под этим пользователем.
3. Открыть `Настройки`.
4. Нажать `Восстановить из копии` и выбрать demo JSON.
5. Проверить данные в разделах `Сегодня`, `Неделя`, `Месяц`, `Тренды`.
6. Если приложение уже подключено к Supabase и пользователь вошёл, импорт обновит облачную копию автоматически. Кнопка `Сохранить в облако` остаётся ручной страховкой.

Демо-аккаунт не должен использовать твой личный email и пароль.
