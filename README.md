# Траектория

«Траектория» помогает увидеть, чем были наполнены дни, недели и месяцы: действия, состояние, события, результаты и мысли. После обзора можно решить, что оставить, изменить или проверить, либо продолжить как есть. Заполнять все поля и давать дню общую оценку не нужно.

Это PWA с личным входом, локальным хранением в IndexedDB и облачной копией Supabase. Приложение работает в браузере и устанавливается на телефон.

## Пользовательский путь

- «Сегодня» — несколько фактов или заметок; состав необязательных блоков настраивается.
- «Обзор» — неделя или месяц, фактические записи и собственные выводы.
- «Тренды» — изменения за несколько месяцев с учётом пропусков и особых дней.
- «Журнал» — завершённые итоги, события и важные мысли.
- Личный эксперимент — одно условие, отметки и свой вывод без автоматической оценки эффекта.

Первый обзор можно восстановить приблизительно без создания вымышленных дневных измерений. Промпт и JSON для внешнего анализа передаются только вручную по решению пользователя; встроенного AI-агента нет.

## Запуск разработки

Нужны Node.js из [.nvmrc](.nvmrc) и npm. В PowerShell используйте `npm.cmd`/`npx.cmd`.

```bash
npm ci
npm run dev
```

Откройте адрес из терминала. Изолированные состояния общих компонентов доступны через `npm run storybook`. Настройка Supabase, обязательного входа и почтовых API — в [BACKEND_AUTH_CI](docs/operations/BACKEND_AUTH_CI.md).

Проверка приложения:

```bash
npm run check
npx playwright install chromium webkit
npm run test:e2e
```

Для Markdown-only изменений применяются отдельные проверки из [PROJECT_RULES](.ai-rules/PROJECT_RULES.md). `npm run format` и `npm run lint:fix` меняют файлы; `check` не исправляет их автоматически.

## Хранение

Запись сначала сохраняется на устройстве, затем обновляет облачный снимок текущего аккаунта. При недоступной сети локальные изменения ожидают синхронизации. Если безопасное слияние невозможно, приложение сохраняет конфликт и предлагает скачать обе копии и явно выбрать версию в настройках.

JSON-экспорт позволяет сохранить отдельную резервную копию. Офлайн-работа не гарантирует фоновую доставку после закрытия приложения: для синхронизации нужно вернуть сеть и открыть его.
