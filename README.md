# Траектория

Персональный offline-first трекер фактов о жизни. Обычный ежедневный чек-ин рассчитан на заполнение менее чем за минуту.

Это первая рабочая версия без регистрации: её можно открыть в браузере, установить на телефон или компьютер и использовать офлайн. Автоматический ИИ-анализ подключается через серверный endpoint, чтобы API-ключ не попадал в браузер.

## Возможности

- сон, качество сна и энергия;
- отдельное поле для времени в кровати, чтобы не смешивать сон и долгое лежание;
- короткий контекст сна и состояния: что мешало или влияло на день;
- вечерние факторы вроде позднего отхода ко сну, новостей, видео, работы или тревоги;
- отметка особого дня: болезнь, поездка, перегруз, событие или восстановление;
- состояние карьерного движения;
- бокс, бачата и другая активность;
- присутствие семьи, чтения, творчества, духовного развития и отдыха;
- свои пункты для карьеры и областей жизни, например «Отклики» или «Питание»;
- отдельный архив важных изменений, решений и жизненных событий;
- отдельный список законченных результатов;
- редактирование событий архива и результатов;
- недельная тепловая карта и короткий обзор;
- недельный и месячный обзор контекста состояния;
- напоминания в конце недели и месяца о разборе периода;
- статистика и локальный анализ за 3, 6 и 12 месяцев;
- локальные подсказки для разбора недели и месяца без платного ИИ;
- экспорт промпта и JSON для GPT прямо из недели, месяца и трендов;
- автоматические наблюдения по связи сна, энергии и движения;
- спокойная сводка повторяющихся факторов без баллов, штрафов и streak-механик;
- пакет и backend endpoint для будущего ИИ-анализа недели и месяца;
- месячная динамика сна, областей жизни и результатов;
- один временный эксперимент;
- локальное хранение и JSON-резервные копии;
- установка как PWA и работа без сети.

## Запуск

```bash
npm install
npm run dev
```

После запуска открой адрес, который покажет терминал (обычно `http://localhost:5173`).

Проверка:

```bash
npm test
npm run build
```

## Хранение данных

Данные находятся в IndexedDB текущего браузера. Для переноса или резервного копирования используй экспорт JSON в настройках.

Если очистить данные сайта или браузера без резервной копии, записи будут потеряны. Облачная синхронизация и аккаунты в эту версию намеренно не входят.

## Веб, PWA и ИИ

План развёртывания и будущей ИИ-интеграции описан в [DEPLOYMENT_AND_AI.md](./DEPLOYMENT_AND_AI.md).

Правила развития продукта, научной осторожности и добавления новых полей описаны в [PRODUCT_RULES.md](./PRODUCT_RULES.md).

Для автоматического ИИ-анализа на хостинге нужен backend endpoint `/api/analyze` и переменная окружения `OPENAI_API_KEY`. Опционально можно задать `OPENAI_MODEL`.
