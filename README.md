# Траектория

Персональный offline-first трекер фактов о жизни. Обычный ежедневный чек-ин рассчитан на заполнение менее чем за минуту.

Это первая рабочая версия без сервера и регистрации: её можно открыть в браузере, установить на телефон или компьютер и использовать офлайн.

## Возможности

- сон, качество сна и энергия;
- короткий контекст сна и состояния: что мешало или влияло на день;
- отметка особого дня: болезнь, поездка, перегруз, событие или восстановление;
- состояние карьерного движения;
- бокс, бачата и другая активность;
- присутствие семьи, чтения, творчества, духовного развития и отдыха;
- свои пункты для карьеры и областей жизни, например «Отклики» или «Питание»;
- отдельный список законченных результатов;
- недельная тепловая карта и короткий обзор;
- недельный и месячный обзор контекста состояния;
- автоматические наблюдения по связи сна, энергии и движения;
- месячная динамика сна, областей жизни и результатов;
- один временный эксперимент;
- локальное хранение и JSON-резервные копии;
- установка как PWA и работа без сети.

## Запуск

```bash
npm install
npm run dev
```

После запуска открой адрес, который покажет терминал (обычно `http://localhost:5173`).

Проверка:

```bash
npm test
npm run build
```

## Хранение данных

Данные находятся в IndexedDB текущего браузера. Для переноса или резервного копирования используй экспорт JSON в настройках.

Если очистить данные сайта или браузера без резервной копии, записи будут потеряны. Облачная синхронизация и аккаунты в эту версию намеренно не входят.
